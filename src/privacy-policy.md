Barefoot Opiniones respeta tu privacidad.

Esta web puede recoger datos técnicos básicos, como dirección IP, tipo de navegador, páginas visitadas o datos de analítica, si se activan herramientas de medición, seguridad o rendimiento.

Si nos contactas por email o formulario, usaremos los datos que nos envíes únicamente para responder a tu consulta.

No vendemos tus datos personales. Podemos usar servicios externos para alojamiento, analítica, email, seguridad o formularios, y esos servicios pueden procesar información según sus propias políticas.

Puedes solicitar acceso, corrección o eliminación de tus datos escribiendo a `info@barefootopiniones.com`.

Esta política puede actualizarse cuando cambien la web, las herramientas utilizadas o los requisitos legales.
